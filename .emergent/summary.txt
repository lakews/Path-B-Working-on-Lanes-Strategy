**Code Architecture**
The project follows a standard structure with a FastAPI backend and a React frontend. The most significant architectural feature is the 5-Lane Highway for trading strategies, which enforces a strict separation of concerns:
1.  **HFT:** Fast, cache-based, non-blocking.
2.  **ALPHA:** Slow, conviction-based, blocking for quality signals.
3.  **GAMMA:** Opportunistic, microstructure-driven.
4.  **SPORTS:** Isolated, external API-driven.
5.  **NEWS:** Hybrid, using an async injection pattern to feed slow analysis into the fast HFT loop.

**Key Technical Concepts**
*   **5-Lane Architecture:** A design pattern to manage multiple trading strategies with different speed and signal quality requirements.
*   **Async Injection Pattern:** A method to decouple slow, blocking operations (like LLM calls) from the high-frequency trading loop. A background service performs the analysis and injects signals into a shared cache, which the main loop can read instantly.
*   **Bayesian Quarantine:** The practice of using separate, isolated Bayesian models for different lanes (Alpha vs. News) to prevent logical contamination.
*   **On-Demand Calculation:** A strategy to ensure data freshness by computing values just-in-time when an API is called, rather than relying on potentially stale values from a background process.
*   **Kelly Criterion:** The core mathematical formula used for position sizing, with different variations (fractional, binary, learned) applied across the lanes.
