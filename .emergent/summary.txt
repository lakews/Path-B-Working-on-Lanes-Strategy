**Key Technical Concepts**
-   **Two-Speed Architecture:** A system design splitting logic into a Fast Path for HFT/execution and a Slow Path for deep analysis (Alpha/LLM) to prevent the execution loop from being blocked by slow computations.
-   **Inventory Skew:** A market-making strategy to manage risk by adjusting quotes based on current inventory. A large long position results in lowering both bid and ask to encourage selling.
-   **Order Flow Imbalance (OFI):** A microstructure signal measuring buy/sell pressure in the order book's top levels to predict short-term price movements and adjust quotes.
-   **Variance-Based Sizing:** A risk technique scaling position size based on Bernoulli variance (), reducing exposure in markets with extreme certainty (price near 0 or 1) or high uncertainty (price near 0.5).
-   **Single Source of Truth UI:** The principle of moving all hardcoded parameters into a centralized UI () to allow for dynamic control without requiring code changes.
