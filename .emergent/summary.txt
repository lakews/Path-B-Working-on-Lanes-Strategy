**Key Technical Concepts**
-   **Dual-Path Architecture:** A fast trigger path (Path B) runs in parallel with a slower intelligence path (Path A).
-   **In-Memory Caching for HFT:** The HFT engine maintains an in-memory dictionary of all active PATH A signals, refreshed from MongoDB every 5 seconds. This provides microsecond-latency O(1) lookups for trading decisions.
-   **Two-Tier LLM Analysis:** A system using two different prompts. A strict Resolution prompt (Tier 1) runs first. If it fails, a looser Sentiment prompt (Tier 2) runs as a fallback.
-   **Tier-Specific Signal Weighting:** Signals from the Sentiment tier have their final Bayes Factor multiplied by 0.5, correctly identifying them as less certain than Resolution signals.
-   **Authoritative Data over Heuristics:** Refactoring the sports market filter to use the  field from the API instead of complex pattern matching, leading to a simpler, more robust solution.
