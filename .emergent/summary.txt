**Key Technical Concepts**
-   **Bayesian Log-Odds Fusion:** The core probability model was refactored to use a log-odds (logit) approach. The market price acts as the prior (anchor), with sentiment and RL signals providing updates (deltas) in log-odds space. This prevents neutral signals from skewing probabilities and is the new source of truth for .
-   **Hybrid Smart-Cache:** An intelligent caching strategy for the LLM sentiment module. It uses different cache Time-To-Live (TTL) settings for hot (high volume) and cold (low volume) markets, which is configurable via the UI to balance API costs and data freshness.
